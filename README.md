🚀 MickTodo - Frontend (React/Next.js)MickTodo est le client web (Frontend) de notre application de gestion de tâches. Il offre une interface utilisateur rapide, réactive et intuitive pour interagir avec l'API du dépot https://github.com/bkam13-dev/micktodo-backend. Développé avec Next.js/React pour la performance et le SEO, et stylisé avec Tailwind CSS pour un développement rapide et modulable.

        🌟 Fonctionnalités Clés
- Création et Gestion de Tâches : Ajoutez, marquez comme complétées, modifiez et supprimez vos tâches rapidement.
- Expérience Utilisateur Moderne : Interface épurée et responsive, garantissant une utilisation agréable sur desktop et mobile.
- Gestion des Erreurs : Notifications utilisateur claires (via react-hot-toast) pour les opérations API.

        ⚙️ Technologies Utilisées

Catégorie - Technologie - Rôle
--------------------------------------------------------------
Framework - Next.js - Base de l'application (Rendu Côté Serveur/Statique).
Librairie UI - React - Construction de l'interface utilisateur.
Styling - Tailwind CSS - Framework CSS utilitaire pour le design rapide et le Responsive Design.
Iconographie - Lucide React - Jeu d'icônes légères et modulables.
API Client - Axios - Client HTTP pour communiquer avec l'API Backend.
Typage - TypeScript - Assure la robustesse et la scalabilité du code.
